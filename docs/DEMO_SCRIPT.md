# KPIT Sparkle Demo Script (4 minutes)

1. Open the command center and point out the mesh, active fleet, and topology map.
2. Run **Agent failure**. AX-003 loses its heartbeat; the event feed shows the orphaned task and local auction.
3. Click any agent marker to show battery, velocity, neighbors, and local task state.
4. Inject a new high-priority task. Explain that peers bid on distance, battery, and communication risk.
5. Run **Communication loss** and show degraded links while the mission keeps moving.
6. Run **100-agent stress** to show the same decentralized contract scales without a central command hub.
7. Close with: “The system does not prevent every failure. It prevents one failure from becoming a fleet failure.”
